Интерактивный каталог товаров с нежно-розовым дизайном, созданный с использованием HTML, CSS и JavaScript. Данные о товарах и категориях загружаются из DummyJSON API.

---

## ✨ Features

- 🔍 **Live Search** — поиск товаров по названию.
- 🏷️ **Category Filtering** — фильтрация товаров по категориям.
- ↕️ **Price Sorting** — сортировка товаров по цене.
- 🖼️ **Product Details** — просмотр информации о товаре в модальном окне.
- 📱 **Responsive Design** — адаптация под разные размеры экранов.
- ⚡ **Loading & Error Handling** — обработка загрузки данных и сетевых ошибок.

## 🛠️ Technologies

- **HTML5** — структура страницы.
- **CSS3** — стилизация и адаптивная вёрстка.
- **JavaScript (ES6+)** — логика приложения и работа с DOM.
- **Fetch API** — получение данных.
- **DummyJSON API** — источник данных о товарах.
